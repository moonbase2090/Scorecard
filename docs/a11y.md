# Accessibility

The `a11y` engine is a static check. It does not open a browser. The web pack runs it on `.html`. The node pack runs it on `.jsx` and `.tsx`. Page rules (`html-lang`, `document-title`, `landmark`) apply to HTML documents, not to a component file.

Findings are warnings. The `a11y` gate is advisory until `--fail-on` names `a11y` or `analyzer.toml` sets `enforce`. Each finding carries a WCAG 2.2 success criterion in `evidence.sc` and in the message. Reports include the file and line. The HTML report groups them under `accessibility`. The score row `a11y` starts at 1.00 and drops by 0.05 for each warning.

Disable a rule by id:

```toml
[a11y]
enforce = false
disable = ["contrast"]
```

| Rule | SC | What it checks |
|---|---|---|
| `img-alt` | 1.1.1 | `img` has an `alt` attribute. An empty alt is allowed. |
| `label` | 1.3.1 | `input`, `select`, and `textarea` have a label, `aria-label`, or `aria-labelledby`. Hidden, submit, button, reset, and image inputs are skipped. |
| `name` | 4.1.2 | `a` and `button` have text, an image alt, or an accessible name. |
| `heading-order` | 1.3.1 | A heading does not skip a level. |
| `html-lang` | 3.1.1 | `html` has a non-empty `lang`. |
| `document-title` | 2.4.2 | The page has a non-empty `title`. |
| `duplicate-id` | 4.1.2 | An `id` is not repeated. WCAG 2.2 removed 4.1.1, so this maps to 4.1.2. |
| `landmark` | 2.4.1 | The page has `main`, `nav`, `header`, `footer`, `aside`, or the matching role. |
| `tabindex` | 2.4.3 | `tabindex` is not greater than 0. |
| `autoplay` | 1.4.2 | `video` or `audio` with `autoplay` also has `controls`. |
| `contrast` | 1.4.3 | Inline `style`, or a same-file `style` rule with a plain tag selector, sets both a foreground and a background below 4.5:1. |

`testdata/a11y_page` is a clean page. `testdata/a11y_page_bad` trips each rule. `testdata/a11y_jsx` is a JSX file with a missing alt.
