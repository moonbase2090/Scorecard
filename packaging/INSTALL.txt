Scorecard 0.1.6 — command-line tools, not a Mac app
====================================================

This disk image holds two command-line programs, `sc` and `sc-mcp`.
There is nothing to drag to Applications. Double-click
`Install Scorecard.pkg` in this window and follow the installer,
which puts both tools in `/usr/local/bin`.

To install from the terminal instead:

  sudo installer -pkg "Install Scorecard.pkg" -target /

Without admin rights, copy the two programs by hand (no sudo):

  mkdir -p ~/.local/bin
  cp sc sc-mcp ~/.local/bin/

If `~/.local/bin` is not on your PATH, add this to `~/.zshrc`
and restart the terminal:

  export PATH="$HOME/.local/bin:$PATH"

Check the install:

  sc --version

The package creates ~/.config/sc/analyzer.toml when that file is absent.
It does not replace a file you already have. To write it yourself:

  sc config init
  sc config path

The package also installs the Scorecard agent skill for coding agents already
configured on this Mac. It runs once per Scorecard version and does not replace
an existing skill file that differs from the bundled copy. To opt out, set
install_agent_skills = false in ~/.config/sc/analyzer.toml, or install from
Terminal with SCORECARD_NO_AGENT_SKILLS=1 in the installer environment.
To install or check the skill later:

  sc skills install --agent detected
  sc skills install --agent all --check

To remove them later, delete the two files from wherever you put them:

  sudo rm /usr/local/bin/sc /usr/local/bin/sc-mcp

The `README.md` in this window is the full manual. `LICENSE.txt` covers
the terms (MPL-2.0).
