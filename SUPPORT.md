# Support

## Questions and help

Open a [discussion or issue](https://github.com/moonbase2090/Scorecard/issues)
with what you ran, what you expected, and the `sc` output. The issue
templates cover bugs and feature requests.

Security issues are **not** handled here, see `SECURITY.md`.

## Supported versions

Scorecard is pre-release. Until the first tagged release, `develop` is the
only supported ref; after that, the latest `vX.Y.Z` tag is supported and
older tags get best-effort answers.
