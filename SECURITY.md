# Security Policy

## Reporting a vulnerability

**Do not open a public issue.** Report private security issues through
[GitHub security advisories](https://github.com/moonbase2090/Scorecard/security/advisories/new)
for this repository.

Include what you found, how to reproduce it, and what you think the impact
is. We will confirm receipt and follow up there.

## Scope

Scorecard is a local-first code quality gate. Reports about the analyzer
engines, the `sc` CLI, the `sc-mcp` server, the GitHub Action, and the
release workflow are all in scope.
